# تقييم الفريق

تطبيق تقييم الفريق والمهام والفواتير.

- الواجهة: `index.html` (منشورة على GitHub Pages)
- الاتصال بقاعدة البيانات: `api.js` (Supabase)
- رابط المدير: `?k=<المفتاح>` ورابط الموظف: `?e=<رمز الموظف>`

الجداول مقفولة، وكل القراءة والكتابة تمر عبر دوال في Supabase تتحقق من المفتاح أو رمز الموظف.
