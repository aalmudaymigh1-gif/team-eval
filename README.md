# إدارة الفريق

تطبيق إدارة الفريق ومشاريع البناء: التقييم والحافز، وتقارير المشاريع، والفواتير والعهد، والرواتب، والحضور.

- الواجهة: `index.html` (منشورة على GitHub Pages)
- الاتصال بقاعدة البيانات: `api.js` (Supabase)
- المدير يدخل بجلسة محفوظة في جهازه (رمز دخول من «الدخول والأجهزة»)، ورابط الموظف: `?e=<رمز الموظف>`

الجداول مقفولة، وكل القراءة والكتابة تمر عبر دوال في Supabase تتحقق من جلسة المدير أو رمز الموظف.
